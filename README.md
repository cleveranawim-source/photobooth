# 4컷 사진

iPad를 세워 두면 그대로 사진 부스가 되는 웹앱입니다. 여러 장을 연속 촬영해 마음에 드는 컷을 고르고,
프레임과 레이아웃을 골라 인화용 이미지를 만든 뒤 **AirPrint로 인화**하거나 **iPad에 저장**합니다.
촬영하던 과정은 짧은 **타임랩스 영상**으로도 남습니다.

서버가 없는 정적 앱이라 GitHub Pages 같은 정적 호스팅에 그대로 올릴 수 있고,
**사진은 iPad 브라우저 안에서만 처리되어 어디로도 전송되지 않습니다.**

👉 **배포 주소: https://cleveranawim-source.github.io/photobooth/**

## 들어 있는 것

- 연속 촬영(기본 6장) → 필요한 수만큼 골라 담기
- **레이아웃 4종** — 세로 4컷 ×2(기본) · 2×2 격자 · 가로 4컷 띠 ×2 · 단컷 폴라로이드
- **인화 프레임 8종** — 네온 아케이드 · 리소 페이퍼 · 모노크롬 스튜디오 · 필름 스트립 · 소다 팝 · 체리 블라썸 · 포레스트 · 크래프트 노트.
  프레임은 **인쇄되는 결과물에만** 적용되고 앱 화면 색은 바뀌지 않습니다 — 대신 프레임을 고르는 자리에서
  고른 레이아웃을 그 프레임 색으로 그려 인화물을 미리 보여줍니다.
- 사진 보정 8종(원본·뽀샤시·화사·선명·따뜻·시원·흑백·빈티지)
- 레이아웃에 맞춰 용지 크기·방향이 바뀌는 AirPrint 인쇄 (4×6인치 / 6×4인치)
- 300dpi의 2배(예: 2400×3600)로 합성 — 인화는 물론 확대해 봐도 깨지지 않습니다
- 촬영 과정 타임랩스 영상 생성·저장
- **관리자 모드**(PIN) — 이름·문구 커스텀, 인쇄 매수, 촬영 컷 수, 카운트다운, 자동 초기화 시간,
  카메라 위치, 손님에게 보여줄 프레임·레이아웃 고르기
- 키오스크 운영 — 화면 꺼짐 방지, 방치 시 자동 초기화, 오프라인 PWA

## 실행

Node.js 20.19 이상이 필요합니다.

```bash
npm install
```

```bash
npm run dev
```

브라우저에서 `http://localhost:4173`을 엽니다. 카메라 없이 흐름만 보려면 첫 화면의
**카메라 없이 샘플로 둘러보기**를 누르세요.

배포용 빌드:

```bash
npm run build
```

## 배포

빌드한 `dist` 를 `gh-pages` 브랜치로 올립니다.

```bash
npm run deploy
```

소스 변경은 `main` 에 따로 커밋·푸시하세요 — `npm run deploy` 는 결과물만 올립니다.

> 푸시할 때마다 자동 배포되게 하려면 GitHub Actions 워크플로를 쓰는 편이 낫지만,
> 현재 `gh` 토큰에 `workflow` 스코프가 없어 워크플로 파일을 푸시할 수 없습니다.
> `gh auth refresh -h github.com -s workflow` 로 스코프를 추가하면 전환할 수 있습니다.

## iPad에서 쓰기

1. iPad Safari로 배포 주소(HTTPS)를 엽니다. **카메라는 HTTPS 또는 localhost에서만 동작합니다.**
2. 공유 → **홈 화면에 추가**. 전체 화면 키오스크로 실행됩니다.
3. 처음 한 번은 온라인 상태로 완전히 로드해 두세요(오프라인 캐시가 채워집니다).
4. **저전력 모드를 꺼 두세요** — 켜져 있으면 화면 꺼짐 방지(Wake Lock)가 거부됩니다.
5. iPad와 프린터가 같은 와이파이에 있어야 AirPrint 목록에 프린터가 뜹니다.

### 관리자 모드

첫 화면의 큰 제목을 **2초간 길게 누르면** PIN 화면이 열립니다. 기본 PIN은 `0000` 이며,
관리자 화면에서 바꿀 수 있습니다. 설정은 그 iPad에만 저장됩니다.

## 알아 둘 점

- **인쇄 매수**는 브라우저 인쇄 대화상자의 매수와 별개로, 같은 이미지를 그 수만큼 페이지로 만들어 보냅니다.
- 홈 화면에 추가한 상태(standalone)에서는 `window.print()`가 막히는 iPadOS 버전이 있어,
  인쇄 버튼이 **공유 시트**로 폴백합니다. 시트의 '프린트'를 고르면 됩니다.
- 카메라 렌즈 위치는 웹에서 알 수 없어 관리자 모드에서 한 번 지정합니다. 지정한 쪽 가장자리에
  카운트다운이 붙어, 숫자를 보는 시선이 자연스럽게 렌즈로 향합니다.
- 캔버스 `context.filter` 는 iPadOS에서 기본 비활성이라 필터가 픽셀 연산으로 폴백합니다.
  결과물이 미리보기와 같아 보이도록 미리보기 레이어 구성을 그대로 굽습니다(`lib/filterEngine.ts`).

## 구조

```
src/
  config/     프레임·레이아웃·필터 정의 (전부 데이터)
  lib/        촬영·필터·합성·인쇄·타임랩스·설정 (화면과 무관한 로직)
  hooks/      카메라, 화면 꺼짐 방지, 자동 초기화
  screens/    환영 · 촬영 · 고르기 · 완성 · 관리자
  components/ 아이콘, 미리보기 조각
  App.tsx     화면 전환과 촬영 시퀀스
```

레이아웃과 프레임은 `src/config/` 의 데이터일 뿐이라, 새로 추가할 때 합성 코드(`lib/compose.ts`)는
건드리지 않아도 됩니다. 사진 칸의 가로세로비가 곧 촬영 크롭 비율이 되므로 칸 크기만 정하면
미리보기까지 따라옵니다.
